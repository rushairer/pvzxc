# PVZXC · 融合花园无尽模式

原生 JavaScript + Canvas 2D + GitHub Pages 的开放式无尽融合塔防项目。

**Alpha 0.5 — 十卡无尽融合**。没有冒险关卡、没有植物解锁等级，直接使用完整的经典 PvZ1 植物种子名录；融合植物通过在同一格继续种植而生成。网页采用原创 Canvas 绘图，不包含官方游戏精灵图、音频或二进制文件。

[在线游戏](https://rushairer.github.io/pvzxc/) · [代码仓库](https://github.com/rushairer/pvzxc) · [自动部署](https://github.com/rushairer/pvzxc/actions)

## 内容规模

| 类别 | 当前版本 |
| --- | --- |
| 基础植物 | 49 张经典植物卡牌，从第一秒全部解锁 |
| 僵尸类型 | 26 类经典 PvZ1 僵尸，随着波数逐步出现 |
| 融合图鉴 | 164 条可识别配方，含部分多级融合 |
| 游戏模式 | 一个无尽战场，持续增加波次，无固定胜利终点 |
| 存档 | 1 个自动槽位 + 3 个手动槽位，读档后恢复战斗 |
| 美术 | Retina/HiDPI 画布、分层草坪、独立植物器官与融合混合造型 |
| UI | 每局固定选 10 张卡，战斗卡槽 5 列 × 2 行；融合配方可搜索 |
| 特殊机制 | 抛射、追踪、冰冻、魅惑、黄油、持续伤害、爆炸、弹坑、墓碑、护甲、磁力、空中目标 |

### 重要的准确性边界

49 张是经典《植物大战僵尸》一代的**完整植物基础种子名录**；26 类是其经典僵尸名录，包括僵王博士。此项目**尚未覆盖《融合版》4.1 的所有新增植物、僵尸、融合配方及特殊关卡**，现有融合效果有部分原创近似，并非全部与融合版完全一致。经典僵尸的特殊行为也处于逐步还原阶段。不会把「名录已经列入」误称为「原作机制全部 1:1 验收完成」。

## 游戏操作

- 开始界面选择 **新建无尽战场** 或 **继续自动存档**。新建存档时须在49张经典种子卡及全部164张融合卡中**选满10张**，选卡支持搜索、基础/融合分类、推荐十张与移除已选。
- 每个存档携带的植物固定 **10 张**，卡槽采用 **5 列 × 2 行**。战斗中按 **1–9、0** 分别选择第 1–10 张卡。不能从图鉴中临时增加卡槽植物。
- 点击草坪种植；在已有植物上再种新植物，会尝试合法融合。无配方时不扣除阳光。
- 所有卡牌与配方一开始就可使用，但花费与冷却正常生效。**在融合图鉴中点击“选用融合植物”**可以把任意高级融合植物选为下一次种植目标（价格按原始材料递归计算），从而使用双融合体组成的配方。
- 点击太阳收集资源。**X** 切换铲子，**G** 切换手套，**V** 在植物/僵尸手套间切换。空格暂停，Esc/右键取消。
- **保存游戏**快速保存至手动存档 1；**读取存档**打开全部槽位的保存、读取和删除面板。
- **Ctrl/Cmd+S** 快捷保存至手动存档 1。
- 返回主菜单会保存当前战斗到自动槽位。

## 存档与恢复

使用当前网页来源的浏览器 localStorage，所有数据都保存在本设备当前浏览器中，不上传服务器。

- **自动存档**：每 15 秒保存，并在页面隐藏/离开与手动返回菜单时保存。
- **手动存档**：槽位 1、2、3 独立保存；可覆盖、读取和删除。
- **保存内容**：本存档的10张卡组、植物布局、融合种类、韧性与南瓜护甲、波数、战斗时间、僵尸类型和位置、弹丸、阳光、资源、卡牌冷却、手套模式/冷却、割草机、弹坑、墓碑、植物内计时器、融合记录。
- **继续游戏**：主菜单直接继续自动存档，或在存档管理里读取指定手动槽位。
- **限制**：清理浏览器站点数据、更换浏览器/设备或使用隐私模式可能使本地存档无法读取；当前不支持账户云同步。最终失守状态本身不能继续游玩，但之前保存的战斗存档可读取。
- **兼容性**：存档有明确的格式版本，无法识别/损坏的存档会报告错误，不会默默覆盖。

## 开发和测试

```bash
npm test
python3 -m http.server 8080
```

在浏览器打开 <http://localhost:8080>。无须 npm install 或打包器。

源码组织：
- `src/model.js`：完整基础卡组、融合规则映射、植物状态
- `src/deck.js`：十张卡组校验、植物库过滤、5×2卡槽几何
- `src/fusions5.js`：第五阶段49条融合扩展配方
- `src/classic.js`：20 张增补的经典植物、26 类僵尸、47 条新增融合
- `src/expansion.js` / `src/expansion3.js`：前两轮新增植物与融合规则
- `src/engine.js`：无尽波次、种植、弹道、碰撞、阳光、植物特殊行为
- `src/zombie-special.js`：经典僵尸的特殊行动处理
- `src/save.js`：版本化存档、校验、序列化与恢复
- `src/render.js`：战场、高 DPI 和交互渲染
- `src/classic-art.js` / `src/fusion-art.js` / `src/zombie-art.js` / `src/art3.js`：独立 Canvas 绘图
- `src/main.js`：UI、自动存档、启动存档、指令快捷键
- `tests/model.test.js`：名录完整性、全部绘图冒烟、存档往返、无尽波次、特殊能力

GitHub Actions 的 `.github/workflows/pages.yml` 在每次推送 `main` 后先运行测试，再发布 GitHub Pages。

## Alpha 0.5（2026-11-08）新增改动

### 每个存档独立十卡选取

- **每次新建无尽档都必须选满十张植物卡**才能开始；原始49种基础卡和164种已实现融合配方全部在选卡库中开放。
- 选定卡组限制了本次可直接种植的植物。战斗中不能借图鉴直接生成未选的高级融合植物；仍可通过持有的卡牌进行正常的就地融合。
- 已有 Alpha 0.4 本地存档的升级策略：旧存档缺少卡组字段时使用推荐十卡恢复战斗，避免破坏战场进度；后续保存会写入卡组。
- 存档之间卡组互相独立，重启浏览器读取存档保持原十卡，不可在已进行的战斗中重新选卡。

### 融合版手套

- 手套提供 **植物手套** 与 **僵尸手套**，两者独立冷却。通过 G 或画面手套按钮选用，V 切换类型。
- 使用植物手套：先点击原植物格，再点击目标草格。移动至空格保留植物血量与当前状态；移动到有合法配方的植物上触发融合，不合法则保留原植物。
- **植物手套冷却 10 秒；僵尸手套冷却 30 秒**。搬运密植/低矮平台类植物时冷却减少至约 3.33 秒，搬运魅惑僵尸冷却 15 秒。
- 僵尸手套可拾取并投放普通僵尸到目标草格，不能直接搬运巨人或僵王博士。移动前选择不消耗冷却；成功投放才进入冷却。
- 点击原位置或 Esc 可取消植物移动。待操作手套状态的拾取过程不写入存档，恢复后可重新选择。

### 融合配方总量 164

本轮新增 49 条涉及火炬树桩、毁灭菇、向日葵和大蒜系的配方；配方名称和输入关系参考融合版 Wiki，**特殊效果及数值仍属于可玩近似，不是官方底层规则的完整复刻**。

手套基本规则参考：[PvZ 融合版 BWIKI / 基本玩法](https://wiki.biligame.com/pvzrh/基本玩法)。
