# 融合花园 · PVZXC

一个基于 **HTML / CSS / 原生 JavaScript / Canvas 2D** 的可玩植物融合塔防实验版本。项目是独立创作，借鉴经典草坪塔防与植物融合玩法，不是原版游戏源码或素材的复制。

## 在线体验

启用 GitHub Pages（Source 选择 **GitHub Actions**）后，地址为：

https://rushairer.github.io/pvzxc/

## 当前 Alpha 0.1 功能

- 5 行 × 9 列草坪；原创绘制植物、僵尸、卡牌、UI
- 8 张植物卡牌、36 种双植物融合配方
- 阳光收集、卡牌消耗与冷却、植物生命值、铲子
- 普通 / 路障 / 铁桶 / 快跑僵尸，以及啃食、冰冻减速、伤害、范围爆炸
- 五波进攻、割草机、胜负结算、重新开始
- 鼠标 / 触屏交互、键盘快捷键、融合图鉴、基础合成音效
- 纯静态网页，不需要服务器、npm 或 API 密钥

## 操作

1. 点击 **开始冒险**。
2. 选上方植物卡牌，点击草坪种下；点击落下的阳光收集。
3. 选另一张植物卡牌，点击已有植物的格子可以融合；需要足够阳光，并且所选组合必须在图鉴中。
4. 按 **1–8** 选卡，**0/X** 铲子，**空格** 暂停，**Esc** 取消选择；也可以在界面点击。
5. 抵挡全部五波僵尸即获胜。

## 本地运行

可以用静态 HTTP 服务器打开（ES module 不适合直接通过 `file://` 加载）：

```bash
python3 -m http.server 8080
```

打开 http://localhost:8080 。

## GitHub Pages

仓库自带 `.github/workflows/pages.yml`。在仓库 **Settings → Pages → Build and deployment → Source** 选择 **GitHub Actions**，随后推送 `main` 或手动运行 **Deploy to GitHub Pages** 工作流即可发布。

## 开发路线

- Alpha 0.1：核心战斗循环、基础双植物融合、原创 Canvas 视觉
- Alpha 0.2：完善战斗平衡、融合特效、音效、触屏适配与自动测试
- Alpha 0.3：更多关卡、敌人种类、关卡选择、存档
- 后续：三级融合、特殊地图、更多植物及僵尸、关卡编辑器
