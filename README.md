# PVZXC · 植物大战僵尸融合版网页复刻项目

目标：以《植物大战僵尸融合版》**4.1** 作为内容参考，尽量还原游戏规则、关卡节奏、UI 结构与融合路径。采用 HTML + Canvas 2D + ES Modules，部署于 GitHub Pages。

> **当前状态：早期开发版本，并非 1:1 完成版。** 已纠正首个原型凭空编造配方、随意设定数值的主要错误。源码不使用原版的二进制文件、贴图、音效和动画，视觉暂以自绘素材占位。原作版权和商标归原权利人所有，本项目并非官方版本。

## 网页与管理

- 游戏网址：<https://rushairer.github.io/pvzxc/>
- GitHub 仓库：<https://github.com/rushairer/pvzxc>

## 分阶段对齐顺序

1. **原版基础规则**：以图鉴与实际视频逐条核对费用、冷却、韧性、伤害、攻速、碰撞、融合前置条件，所有差异进入测试。
2. **视觉与操作**：修正卡槽、计数器、草坪比例、攻击与啃食动画；采用自行设计、具有辨识度的素材，不直接照搬原版受保护资源。
3. **融合图谱**：先覆盖白天植物全部合法的一/二/三级融合、交叉融合、属性继承、触发效果，再扩展其余系列。
4. **关卡和敌人**：重建进攻时间线、旗帜、大波、奖励；扩展僵尸种类与特殊关卡。
5. **完整验收**：逐项回归原作实机录像，建立对应的自动化功能和视觉检查，才可宣称特定模块完成还原。

## 操作

选择植物卡牌（键盘 1–7，左右方向键翻页），再点草格。将某植物放在已种植物上会尝试融合；不能融合时不会扣费。点击阳光收集。0/X 切换铲子，空格暂停，Esc / 右键取消。五路任一路失去最后防线即失败。

## 结构

- `src/model.js`：数据驱动植物及融合图谱
- `src/expansion.js`：新植物与拓展融合配方
- `src/engine.js`：战斗规则、碰撞、阳光、波次、关卡
- `src/render.js`：程序绘制草坪、植物、僵尸、交互反馈
- `src/main.js`：UI 事件与状态衔接
- `tests/model.test.js`：自动化回归
- `docs/REFERENCE.md`：参考资料与准确性边界
